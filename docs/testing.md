# Testing

Details behind the test commands in [CLAUDE.md](../CLAUDE.md). None of these suites are part of `./check.sh`, which stays dependency-free and network-free.

Unit tests (pytest) cover the pure logic in `tools/py/pdf-signer.py` (`match_name_box`, `signature_rect`, `locate_signer`, `batch`) and `tools/py/pdf-print-marks.py` (`looks_like_surname`, `find_surname_boxes`, `target_count`, `mark_rect`) in `tests/py/`. Run them with `./test.sh` (extra args go to pytest, e.g. `./test.sh -k locate`): it runs pytest in the signer's venv (`SIGNER_VENV_DIR`/`SIGNER_PACKAGES` in `tools/common.sh`, shared with `pdf-signer.sh`) and installs pytest there on first use, touching pip only when something is missing. The tests are deliberately not part of `check.sh` (which stays dependency-free and network-free), but `checks/python.sh` lints and type-checks them. OCR (`_ocr_words`) and PDF I/O (`stamp`) are not unit-tested; run the tool for those. When adding Python logic to a tool, keep the pure part separate from OCR/PDF calls so it can be tested with fake data.

Bash unit tests (bats-core, `sudo apt install bats`) cover the pure logic in `tools/common.sh` (`clean_path`, `ensure_extension`, `default_output_name`), `pdf-tools.sh` (`resolve_tool`) and `tools/pdf-compressor.sh` (`format_mb`, `search_best_dpi`), in `tests/bash/`. Run them with `./test-bash.sh` (extra args go to bats, e.g. `./test-bash.sh -f resolve_tool`). This works by sourcing the scripts directly: `pdf-tools.sh` and `pdf-compressor.sh` guard their interactive body (menu loop / dependency check + prompts) behind `if [[ "${BASH_SOURCE[0]}" == "$0" ]]; then ... fi`, so sourcing them for tests defines the functions without running the CLI or requiring `gs`/stdin. `common.sh` needs no such guard — it has no top-level executable logic. Like the pytest suite, `tests/bash/` is deliberately not part of `check.sh`; add the same source-guard when a new script gains testable pure logic.

End-to-end tests (bats, `tests/e2e/`) run `pdf-compressor.sh`, `pdf-signer.sh`, `pdf-print-marks.sh` and `pdf-to-video.sh` through their real prompts by piping answers into stdin, on fixtures that `tests/e2e/make_fixtures.py` generates per test (noise PDF; 3 text pages; a Ukrainian-text "scan" for OCR; a signature PNG) with the signer's venv. Run them with `./test-e2e.sh` (extra args go to bats, e.g. `./test-e2e.sh -f signer`; ~20 s). Each test skips itself when its dependency (`gs`, `ffmpeg`/`ffprobe`/`pdftoppm`, `tesseract-ocr-ukr`, the signer venv) is missing, and the suite is not part of `check.sh`. Not covered yet: `pdf-a5-print.sh`, `pdf-contrast-enhancer.sh`. `helpers.bash` holds the shared skip/fixture helpers.
